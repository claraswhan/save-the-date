# Wedding Events Page

A beautiful, elegant wedding events page inspired by Minted's design style.

## Features

- Clean, modern design with elegant typography
- Responsive layout that works on all devices
- Smooth scrolling navigation
- Event timeline with detailed information
- Travel and accommodation information
- Scroll animations for enhanced user experience

## Structure

- `index.html` - Main HTML structure
- `styles.css` - Complete styling with CSS variables
- `script.js` - Interactive functionality and animations
- `README.md` - This file

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --color-primary: #d4a574;
    --color-primary-dark: #b8936a;
    /* ... */
}
```

### Content
- Update event details in `index.html`
- Modify dates, times, and locations
- Add or remove events as needed

### Fonts
Currently using Google Fonts (Playfair Display & Lato). You can change these in the `<head>` section of `index.html`.

## Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge).
